# Expense Tracker

A modern full-stack Expense Tracker application built with Next.js, TypeScript, Redux Toolkit, Tailwind CSS, and shadcn/ui.

## Features

- User Authentication
  - Register
  - Login
  - Logout
  - Forgot Password
  - OTP Verification
  - Reset Password

- Dashboard Analytics
  - Expense Summary
  - Monthly Expense Chart
  - Category Expense Chart

- Expense Management
  - Add Expense
  - Update Expense
  - Delete Expense
  - Pagination
  - Search Expenses
  - Filter by Month

- Budget Management
  - Create Monthly Budget
  - Track Spending

- Profile Settings
  - Update Profile
  - Upload Profile Image

- Modern UI
  - Responsive Design
  - Dark Mode Support
  - shadcn/ui Components
  - Recharts Analytics

---

## Frontend

- Next.js 16
